# ระบบติดตามสถานะการประเมินผลงาน (อวช.)

- Frontend: `index.html` (ไฟล์เดียว) บน GitHub → Vercel — https://hrsansaihospital.vercel.app/
- Backend: Google Apps Script + Google Sheets (`Code.gs`) พร้อม LINE Messaging API
