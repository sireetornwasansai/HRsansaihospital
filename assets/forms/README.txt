เอกสาร/แบบฟอร์มสำหรับผู้ยื่น (แท็บ "เอกสาร/แบบฟอร์ม")
forms.json = รายการเอกสารและการจัดกลุ่มตามระดับ (แก้ชื่อ/คำอธิบายได้)
files/ = ไฟล์จริง   covers/ = รูปปก (card=ย่อ, large=ใหญ่)
เปลี่ยนไฟล์: วางทับชื่อเดิมใน files/ แล้วแก้ "kb" ใน forms.json
เพิ่มเอกสาร: วางไฟล์ใน files/ -> เพิ่มใน "docs" -> ใส่รหัสใน "docs" ของระดับที่เกี่ยวข้อง
ถ้าต้องการปุ่มดูตัวอย่าง ใส่ "preview" เป็นไฟล์ PDF
forms.json ต้องเป็น JSON ที่ถูกต้อง
