ตอนที่ 7

แท็บอื่นๆ — LINE · คำถามที่พบบ่อย · ผู้ใช้ · ประวัติ

รายการผลงานLINEคำถามที่พบบ่อยผู้ใช้ประวัติการใช้งานแท็บ LINE · ผู้ใช้ · ประวัติการใช้งาน เห็นเฉพาะ ผู้ดูแลระบบ ส่วน คำถามที่พบบ่อย เจ้าหน้าที่ทุกคนใช้ได้

แท็บ LINE

ผู้ดูแลระบบ

ใช้ดูแลการส่งข้อความ LINE ถึงผู้ยื่น เปิดดูเมื่อผู้ยื่นบอกว่าไม่ได้รับข้อความ

  1. 1ข้อความไม่ถึงใครเลย: กดปุ่ม “ตรวจสอบการเชื่อมต่อ” ระบบทดสอบการเชื่อมต่อกับ LINE และแสดงที่อยู่ Webhook ถ้าขึ้นแจ้งปัญหา ให้ส่งข้อความนั้นให้ผู้ดูแลระบบ/ผู้พัฒนา
  2. 2ผู้ยื่นเพิ่มเพื่อนแล้วแต่ยังไม่ผูก: ดูตาราง “เพิ่มเพื่อนแล้วแต่ยังไม่ผูก” มีชื่อ LINE เวลา ข้อความล่าสุด และ “ผู้ยื่นที่น่าจะตรง” ให้กดชื่อผู้ยื่นที่ตรงเพื่อผูก ถ้าไม่มีชื่อตรง กด “ใช้ userId นี้” แล้วกรอกเลขบัตรประชาชนเอง
  3. 3ตรวจย้อนหลัง: ตารางล่างสุดคือประวัติข้อความ (เวลา · รหัส/ผู้รับ · ประเภท · ผู้ส่ง · ข้อความ · ผลลัพธ์) ใช้ดูว่าข้อความที่ส่งออกไปสำเร็จหรือไม่
ผูกให้ผิดคน = ข้อความของคนหนึ่งไปถึงอีกคน ตรวจเลขบัตรและชื่อให้ตรงก่อนกดทุกครั้ง

แท็บ คำถามที่พบบ่อย

เจ้าหน้าที่ทุกคน

คำถามที่ผู้ยื่นเปิดอ่านได้เองโดยไม่ต้องเข้าสู่ระบบ ช่วยลดจำนวนคนโทรถาม

  1. 1กด “เพิ่มคำถาม” แล้วกรอก หมวดหมู่ · ลำดับแสดง (เลขน้อยขึ้นก่อน) · คำถาม · คำตอบ (ไม่เกิน 3,000 ตัวอักษร พิมพ์ลิงก์ https://… ระบบทำเป็นลิงก์ให้)
  2. 2ติ๊ก “เผยแพร่” ถ้าพร้อมให้ผู้ยื่นเห็น ไม่ติ๊ก = ฉบับร่าง (ผู้ยื่นไม่เห็น) ติ๊ก “ปักหมุด แนะนำ” เพื่อให้ขึ้นก่อนข้ออื่น แล้วกด “บันทึก”
  3. 3กด “ดูหน้าที่ผู้ยื่นเห็น” เพื่อตรวจว่าแสดงถูกต้อง คอลัมน์ “ความเห็น” คือจำนวนคนที่กดว่าเป็นประโยชน์/ไม่เป็นประโยชน์ ข้อที่ไม่เป็นประโยชน์เยอะ ควรเขียนใหม่
ผู้ยื่นถามเรื่องเดิมซ้ำ 3 ครั้งขึ้นไป ให้เพิ่มเป็นคำถามที่พบบ่อย แล้วตอบผู้ถามพร้อมลิงก์ไปหน้านั้น

แท็บ ผู้ใช้

ผู้ดูแลระบบ

จัดการว่าใครเข้าระบบนี้ได้ ใช้เมื่อมีเจ้าหน้าที่ใหม่ ย้าย หรือลืมรหัสผ่าน

  1. 1เพิ่มเจ้าหน้าที่ใหม่: พิมพ์ชื่อ นามสกุล หรือเลขบัตร (อย่างน้อย 2 ตัวอักษร) เพื่อค้นหาจากทะเบียนบุคลากร → เลือกคนที่ถูกต้อง
  2. 2ตั้ง ชื่อผู้ใช้ (ค่าเริ่มต้นคือเลขบัตร แก้ได้) และ รหัสผ่านเริ่มต้น (อย่างน้อย 8 ตัว) เลือก สิทธิ์: เจ้าหน้าที่ (จัดการผลงานได้) หรือ ผู้ดูแลระบบ (ทำได้ทุกอย่าง) → กด “เพิ่มผู้ใช้”
  3. 3ลืมรหัสผ่าน: ที่แถวของคนนั้นกดตั้งรหัสผ่านใหม่ ผู้ใช้ต้องใช้รหัสใหม่ตั้งแต่ครั้งถัดไป
  4. 4คนลาออก/ย้าย: กด “ปิดใช้งาน” บัญชีเข้าไม่ได้ทันที ประวัติเดิมยังอยู่ ถ้ากลับมากด “เปิดใช้งาน”
ให้สิทธิ์ “ผู้ดูแลระบบ” เฉพาะคนที่จำเป็น เพราะลบรายการและดูประวัติได้ ส่งรหัสผ่านเริ่มต้นให้เจ้าตัวโดยตรง ไม่ส่งในกลุ่มแชต

แท็บ ประวัติการใช้งาน

ผู้ดูแลระบบ

สมุดบันทึกของระบบ ว่า “ใคร ทำอะไร เมื่อไร” ใช้ตรวจสอบเมื่อข้อมูลเปลี่ยนโดยไม่รู้ที่มา

  1. 1เปิดแท็บ จะเห็นตารางเรียงจากล่าสุด: เวลา · กิจกรรม · ผู้ใช้ · ผลลัพธ์ · รายละเอียด
  2. 2ค้นรหัสเรื่อง (เช่น AWC-…) ด้วยปุ่มค้นหาของเบราว์เซอร์ (Ctrl + F) เพื่อดูทุกอย่างที่เกิดกับเรื่องนั้น
ชื่อกิจกรรมที่พบบ่อย:
admin_hist_time = แก้ไขวันที่ย้อนหลัง (มีเวลาเดิม → เวลาใหม่) · star_on / star_off = ติดดาว / เอาดาวออก · admin_delete = ลบรายการ · login = เข้าสู่ระบบ
ลบหรือแก้ไม่ได้ จึงเชื่อถือได้เวลามีข้อสงสัยว่า “ใครเป็นคนแก้วันที่”
ฝึกก่อนใช้จริง

ปุ่ม “โหมดจำลองข้อมูล”

อยู่ในหน้า “เจ้าหน้าที่ HR” (หลังเข้าสู่ระบบ) เปิดแล้วจะมีข้อมูลตัวอย่างให้ทดลองกดทุกปุ่มได้เต็มที่ ไม่กระทบข้อมูลจริง ไม่เขียนลงชีท และไม่ส่ง LINE หรืออีเมลจริง ปิดแท็บหรือกดออกแล้วข้อมูลตัวอย่างหายหมด

แนะนำสำหรับเจ้าหน้าที่ใหม่
1. เปิดโหมดจำลอง
2. ลองอัพเดทสถานะจนครบเล่ม 1
3. ลองแก้วันที่ย้อนหลัง และติดดาว
4. ลองส่งแจ้ง LINE และตอบคำถาม
5. ปิดโหมดจำลอง แล้วเริ่มงานจริง
