## เพิ่มเติม (รอบล่าสุด)
- **ผู้ใช้ ↔ allstaff:** `apiStaffSearch_` (อ่าน allstaff อย่างเดียว) → `apiUserAdd_` (สร้างใน Users พร้อมเลขบัตรอ้างอิง) → `apiUserEdit_` (ชื่อ/สิทธิ์/รีเซ็ตรหัส) → `apiUserToggle_`
- **แบบฟอร์มยื่น:** วุฒิการศึกษาสูงสุด, คำนำหน้า 100+ ตัวเลือก (ทั่วไป/วิชาชีพ/วิชาการ/ว่าที่/ยศทหาร/ยศตำรวจ/ระบุเอง), ช่องชื่อผลงาน (กรอกตอนยื่น เจ้าหน้าที่แก้ไขได้), กล่อง QR LINE OA
- **LINE:** เหตุการณ์ "เพิ่มเพื่อน" บันทึก userId ใน `LineLog` (ผู้ดูแลใช้ผูกให้ได้จากแท็บ LINE)
- **FTE:** ฟังก์ชัน `api_*` ทั้ง 42 รายการเรียกผ่าน `doPost` (ผลลัพธ์อยู่ใน `data`) โดยหน้า `/fte/` ใช้ตัวแทน `google.script.run`
- **ความเร็ว (GAS):** `ss_()` เก็บ Spreadsheet และ `sheet_(key)` เก็บ Sheet ไว้ใน `_SS`/`_SHT` ต่อ execution · `findSub_(id)` อ่านเฉพาะคอลัมน์รหัสแล้วอ่านแถวเดียว (ใช้ `subObj_` ร่วมกับ `subs_()`)
- **ความเร็ว (หน้าเว็บ):** `boot()` ยิง `config` กับ `verify` พร้อมกัน และแสดง config ที่แคชใน `localStorage` (`awc_cfg`) ก่อน · CSS ไอคอน/ฟอนต์โหลดแบบไม่บล็อกการแสดงผล (`media=print` + `onload`)
- **ซ่อมประวัติสถานะ:** `cleanHistoryDryRun` (ตรวจอย่างเดียว) / `cleanHistoryApply` (สำรองแท็บแล้วเติม 0 ชั่วโมงเวลาที่เป็นหลักเดียว + ลบแถวที่ซ้ำทุกช่อง)
- **ความเร็ว (GAS รอบ 2):** `prop_` อ่าน Script Properties ครั้งเดียวต่อการรัน (ผู้เขียนค่าใช้ `setProp_`) · `log_` ใช้ `appendTextLite_` (ข้ามตั้งรูปแบบ+flush เมื่อแถวเป็น @ อยู่แล้ว) · `apiTrack_` นับรอบแก้ไขจาก `fixFromHis_` (ไม่อ่านแท็บประวัติซ้ำต่อเคส) · `installWarmTrigger`/`removeWarmTrigger` (ทริกเกอร์อุ่นเครื่องทุก 5 นาที เลือกใช้)
- **สี/สถานะหน้ารายงาน:** ชิปและป้ายระยะเวลาในสรุปกระบวนการใช้สีประจำเล่ม (`bTone`) · ตารางทบทวนความล่าช้าแสดงสีแดงเฉพาะขั้นที่ยังรอทบทวน ขั้นที่ทบทวนครบแสดงเขียว "ทบทวนครบแล้ว"
