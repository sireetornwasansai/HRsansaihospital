# สรุปฟังก์ชันตามความต้องการ (Function Spec)

| # | ความต้องการ | Backend (Code.gs) | Frontend (index.html) |
|---|---|---|---|
| 1 | หลังค้นหา แสดงหน้าติดตามสถานะ: ชื่อ, ขั้นตอน 5 ระดับ, หมายเหตุ, ประวัติ, ไฟล์/ข้อความจาก HR | `apiTrack_` (items + history + notes) | หน้า "ติดตามสถานะ" (`#track`) |
| 2 | LINE: ผูกบัญชี 2 ปัจจัย (เลขบัตร + เลขท้ายเบอร์โทร 4 ตัว) → รหัส 6 หลัก → พิมพ์ในแชท OA | `apiLineLinkReq_`, `apiLineLinkCheck_`, `lineWebhook_`, `lineConsume_` | ปุ่ม "เชื่อมต่อ LINE" (ตรวจสถานะการผูกอัตโนมัติ) |
| 2 | ประวัติการกดแจ้งเตือน/ส่ง LINE ต่อรายการ + ภาพรวมผู้ดูแล | `apiLineInfo_`, `apiLineAdmin_`, แท็บ `LineLog` | แผงแจ้งเตือนในรายการ + แท็บ LINE |
| 2 | แจ้งเตือนแบบพิมพ์เอง / ข้อความสำเร็จรูป / ส่งการ์ดสถานะ | `apiLineSend_` (mode=text\|status, kind=typed\|manual) | ฟอร์มพิมพ์ข้อความ |
| 3 | เปลี่ยนสถานะ/หมายเหตุ → ส่ง LINE อัตโนมัติถึงทุก userId ที่ผูก พร้อมรายละเอียด | `apiAdminSave_` → `autoNotify_` → `flexStatus_` | ฟอร์มแก้ไขของ HR (สวิตช์ `sendLine`) |
| 4 | สถานะสอดคล้องกับหน้าติดตาม | แหล่งเดียว: แท็บ `ยื่นอวช` + `ประวัติสถานะ` (HIS) | หน้าติดตามอ่านจาก `apiTrack_` |
| 5 | แนบรูป/ไฟล์ส่งไปกับ LINE (jpg/png/pdf/doc/docx/xls/xlsx ≤ 8 MB) | `saveUpload_` (ตรวจนามสกุล+ขนาด+ลายเซ็นไฟล์) + `flexFile_` | ช่องแนบไฟล์ (บีบอัดรูปก่อนส่ง) |
| 6 | ปุ่ม/Loading ตอบสนอง | ทุก API คืน `{ok,message}` | แถบโหลด, aria-busy, toast, timeout 45 วิ |

## แท็บที่ระบบสร้างเอง
`ยื่นอวช`, `ประวัติสถานะ`, `Users`, `Notifications`, `ActivityLog`, `LineUsers`, `LineLog` (อ่านแท็บ `allstaff` ของเดิม)

## ขั้นตอนสถานะ (แก้ที่ `STAGES`)
ยื่นเอกสารแล้ว → ตรวจคุณสมบัติ (HR) → อยู่ระหว่างกรรมการตรวจผลงาน → ต้องแก้ไข → ผ่านการประเมิน
