## แท็บที่ระบบสร้างเอง
`ยื่นอวช`, `ประวัติสถานะ`, `Users`, `Notifications`, `ActivityLog`, `LineUsers`, `LineLog`, `ถังขยะ` (อ่านแท็บ `allstaff` ของเดิม)

## ขั้นตอนสถานะ (แก้ที่ `STAGES`)
ยื่นเอกสารแล้ว → ตรวจคุณสมบัติ (HR) → อยู่ระหว่างกรรมการตรวจผลงาน → ต้องแก้ไข → ผ่านการประเมิน

## เพิ่มเติม (รอบล่าสุด)
- **ผู้ใช้ ↔ allstaff:** `apiStaffSearch_` (อ่าน allstaff อย่างเดียว) → `apiUserAdd_` (สร้างใน Users พร้อมเลขบัตรอ้างอิง) → `apiUserEdit_` (ชื่อ/สิทธิ์/รีเซ็ตรหัส) → `apiUserToggle_`
- **แบบฟอร์มยื่น:** วุฒิการศึกษาสูงสุด, คำนำหน้า 100+ ตัวเลือก (ทั่วไป/วิชาชีพ/วิชาการ/ว่าที่/ยศทหาร/ยศตำรวจ/ระบุเอง), ไม่มีช่องชื่อผลงาน, กล่อง QR LINE OA
- **LINE:** เหตุการณ์ "เพิ่มเพื่อน" บันทึก userId ใน `LineLog` (ผู้ดูแลใช้ผูกให้ได้จากแท็บ LINE)
- **FTE:** ฟังก์ชัน `api_*` ทั้ง 42 รายการเรียกผ่าน `doPost` (ผลลัพธ์อยู่ใน `data`) โดยหน้า `/fte/` ใช้ตัวแทน `google.script.run`
